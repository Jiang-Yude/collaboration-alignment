# collaboration-alignment

合作對齊一條龍：從「聊得很開心沒下文」到「合作真的開始動」的完整 SOP。

---

## 為什麼做這個

合作初期最常見的死法：聊很開心，然後就沒下文了。或是開始做了，才發現大家對「這件事」的想像根本不一樣。

我把自己處理跨組織合作、社團合作、自由工作者合作時摸索出來的流程，整理成這個技能包。九個階段，從目標對齊到對齊簡報到部署，一條龍走完。

---

## 它能做什麼

- **遠中近目標對齊**：用三層時間軸（近 1-2 月 / 中 3-6 月 / 長 6-12 月）把大家的預期攤開，找出對齊層或斷點
- **雞蛋火腿識別**：找出合作中的不對等負擔。誰是每天生蛋的雞、誰是要割腿的豬
- **合作共識地圖**：用 AI 把對話整理成一份地圖，讓利潤分配、責任歸屬這類敏感話題有自然的開口
- **會議前快速對焦**：多方模糊案（多人牽線 + 訴求混雜）的三段時程準備（遠 / 中 / 近，尺度是週到天）
- **對齊簡報**：主導者主動做一份簡報，自己想清楚的部分先定、對方主場明確留白。跟提案簡報、會議簡報都不同，定位是「我先到這，你來補」
- **視覺工具箱**：留白方塊（提案型）、AB 圖（洞察型：人關係網路 + 議題優先矩陣）、紅綠燈（通用）
- **跨模型共思 SOP**：避免單一模型盲點，主審跨家族、同家只輔審
- **減法迭代**：每一輪砍冗餘、聚焦核心，對齊簡報是草案不是成品

---

## 它不做什麼

- 不適用上下級關係（老闆對員工）
- 不適用強制出席的組織內部會議
- 不替任何一方做決定，只呈現選項、留討論空間
- 不代替使用者去跟合作對象溝通或簽約

## 安裝

把這個 repo clone 到你的 AI 技能包資料夾：

```bash
git clone https://github.com/Jiang-Yude/collaboration-alignment ~/.claude/skills/collaboration-alignment
```

或手動下載放到 `~/.claude/skills/collaboration-alignment/`。

跟你的 AI 說：「讀 collaboration-alignment/SKILL.md，然後幫我做合作對齊。」

## 跟 AI 辦公室全家桶的關係

這個技能包是 [AI 辦公室全家桶](https://github.com/Jiang-Yude/ai-office-workshop) 的一部分。

全家桶涵蓋：個人知識管理、內容寫作、會議記錄、合作對齊、網頁部署等完整工作流。這個 repo 是其中「合作對齊」模組的獨立開源版，可以單獨使用，也可以搭配全家桶一起用。
