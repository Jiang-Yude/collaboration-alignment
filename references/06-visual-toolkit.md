# 06 · 視覺工具箱

> 對齊簡報專用的視覺化規格。
> 三件套：**留白方塊**（提案型）、**AB 圖**（洞察型）、**紅綠燈**（通用）。

---

## 視覺工具一｜留白方塊（提案型必用）

### 視覺特徵

- **顯眼的虛線邊框**（不要實線，實線視覺上像「已定」）
- **米色／柔色背景**（跟主內容區隔）
- **「給對方思考」明顯 label**
- **引導性 hint 文字**（不是空白）

### CSS 規格範例

```css
.placeholder-block {
  border: 2px dashed #c4a878;
  background: #f5f1e8;
  padding: 24px;
  border-radius: 8px;
  margin: 32px 0;
}

.placeholder-block .label {
  display: inline-block;
  background: #6b3410;
  color: white;
  padding: 4px 12px;
  border-radius: 4px;
  font-weight: bold;
  margin-bottom: 12px;
}

.placeholder-block .hint {
  color: #6b3410;
  font-style: italic;
  margin-top: 12px;
}
```

### 內容範例

> **【給合作對象思考】**
>
> 這兩個動作的具體交付內容、流程設計、產出格式，
> 留給你自己想，想好再補進來。
>
> *引導問題：會前會議要問哪些？引導環節三小時做什麼？產出物是什麼？*

## 視覺工具二｜AB 圖（洞察型必用）

兩張圖一組：A 看「人和事如何牽動」，B 看「下一步該動哪個」。

### A 圖｜議題-人關係網路圖

**用途**：看人和議題如何牽動。

**規格**：

| 元件 | 規則 |
|---|---|
| **節點** | 人（圓圈）+ 議題（方塊），分開兩種形狀 |
| **線條型態（4 種）** | 主推（粗實線）／協作（細實線）／校準（點線）／異議瓶頸（紅寬虛線） |
| **線條顏色** | 起點是誰 = 該顏色（讓觀者看到誰在主推誰的議題） |
| **議題框顏色** | 優先級（綠 = 優先 / 黃 = 中 / 紅 = 暫緩） |
| **節點旁註** | 角色標籤（如：召集者、提供者、校準者、敲門者） |

### B 圖｜議題優先矩陣

**用途**：看下一步該動哪個。

**規格**：

| 元件 | 規則 |
|---|---|
| **X 軸** | 立即可動性（低 → 中 → 高） |
| **Y 軸** | 主導者注意力分數（0 → 10） |
| **四象限** | 右上「立即動」／左上「需準備」／右下「機會主義」／左下「暫不推」 |
| **點顏色** | TA 清楚度（綠 = 高 / 黃 = 中 / 灰 = 未評估 / 紅 = 不明） |
| **點大小** | 重要性／優先級 |
| **點上數字** | 主導者注意力分數 |

### AB 圖的搭配邏輯

- A 圖回答「**誰**在牽動**什麼**」（結構分析）
- B 圖回答「**現在**該動**哪個**」（行動排序）
- 兩張並排，左 A 右 B，配色互相呼應

## 視覺工具三｜紅綠燈系統（通用）

### 燈號定義

| 燈號 | 含義 | 顏色碼 |
|---|---|---|
| 綠燈 | 優先推進，主導者主動投入 | `#10b981` |
| 黃燈 | 中等優先，看機會推進 | `#f59e0b` |
| 紅燈 | 暫不推進，需更多條件成熟 | `#ef4444` |
| 灰燈 | 未評估，待補資料 | `#9ca3af` |

### 使用場景

- 對齊簡報的議題清單
- 多方共識的訴求清單
- 任務優先級盤點
- 合作對象的態度評估

---

## 配色語意（主導者 vs 對方）

對齊簡報的配色有語意，每個角色對應固定色系：

| 角色 | 顏色 | 用法 |
|---|---|---|
| **對方主場** | 咖啡色（`#6b3410`） | hero badge、留白方塊邊框、對方欄表頭 |
| **主導者主場** | 深藍色（`#2c5f7a`） | hero accent、主導者欄表頭 |
| **留白區** | 米黃色（`#f5f1e8`）+ 虛線邊框 | 給對方思考的方塊 |
| **共識區** | 中性色（`#737373`） | 雙方都同意的部分 |

觀者一眼看到顏色，就知道**這塊是誰主導的**。

---

## 對照表規格（如有多方案）

- **一眼看出差別 > 完整資訊**
- 5-6 列以內（超過會雜）
- **每 cell 一句話**（不要寫段落）
- 主導者欄底色用該角色色系
- 最後一列可以跨欄寫共同提醒
